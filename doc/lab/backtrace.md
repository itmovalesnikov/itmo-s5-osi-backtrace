# Задание. Backtrace

## Введение

Сейчас в `Xv6` при сбое процесса невозможно понять,
по какому пути выполнения он пришёл к ошибке —
ядру недоступен backtrace ни из user-space, ни из
kernel-space. Backtrace — необходимый объект для
отладки и диагностики.

## Задача

В ядре ОС реализуйте процедуры для получения backtrace
со стеков как в userspace, так и в kernelspace.

Сам backtrace представляет собой список/массив адресов.

Рекомендуется выразить backtrace в виде отдельной
программной сущности.

Также реализуйте и продемонстрируйте работу процедуры по
печати backtrace в терминал.

Печатайте backtrace при вызове panic.

Реализуйте скрипт для преобразования списка адресов
в понятное человеку текстовое представление функций
(symbolize an address).

## Демонстрация

Соберите и запустите xv6 командой `make qemu`, затем выполните в ней
`backtracetest`. Команда выводит backtrace ядра и пользовательской программы.
При `panic` backtrace ядра выводится автоматически.

Для преобразования адресов используйте соответствующий ELF-файл на хосте:

```sh
sh symbolize.sh kernel/kernel 0x80000000
sh symbolize.sh user/_backtracetest 0x0000000000000000
```

Вместо приведённых примеров передайте адреса из вывода. Также адреса можно
передать по одному в строке через стандартный ввод. Адреса в backtrace являются
адресами возврата, поэтому для определения строки вызова иногда следует
вычесть из адреса единицу. Оптимизации и ассемблерные функции без кадрового
указателя могут сокращать цепочку вызовов.
